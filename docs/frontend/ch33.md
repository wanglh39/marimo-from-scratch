# CodeMirror 6 集成：EditorView、updateListener、外部同步

notebook 的代码编辑器是核心组件。marimo 前端用 CodeMirror 6（CM6），不是 Monaco 或 Ace。CM6 模块化、轻量、可 tree-shake，适合教学项目。但它的 API 是命令式且自管理 DOM，与 React 的声明式模型有张力，需要小心封装。

## CM6 的两个核心对象

- **EditorState**：不可变的编辑器状态（文档内容、选区、扩展配置）；
- **EditorView**：可变的视图，持有 DOM 和当前 state，提供 `dispatch` 改变状态。

创建编辑器：

```typescript
const view = new EditorView({
  state: EditorState.create({
    doc: initialCode,
    extensions: [python(), keymap.of([...]), updateListener],
  }),
  parent: divRef.current,
});
```

`python()` 提供 Python 语法高亮（来自 `@codemirror/lang-python`），`keymap` 绑定快捷键，`updateListener` 监听文档变化。

## React 封装的难点

React 组件每次 render 会重新执行函数体，但 CM6 的 view 不能每次都重建——重建会丢光状态、闪烁、卡顿。所以要用 `useRef` 持有 view 实例，`useEffect` 里创建一次、卸载时销毁：

```typescript
function CodeEditor({value, onChange, onRun}) {
  const viewRef = useRef<EditorView>();
  const divRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const view = new EditorView({
      state: EditorState.create({
        doc: value,
        extensions: [
          python(),
          keymap.of([{key: "Shift-Enter", run: () => { onRun(); return true; }}]),
          EditorView.updateListener.of(v => {
            if (v.docChanged) onChange(view.state.doc.toString());
          }),
        ],
      }),
      parent: divRef.current!,
    });
    viewRef.current = view;
    return () => view.destroy();
  }, []);

  return <div ref={divRef} />;
}
```

`useEffect` 依赖空数组，只在 mount 跑一次。

## 外部 value 同步

上面封装有个 bug：`value` prop 变了（比如后端 `update_cell` 推回新代码），编辑器不会更新。需要外部 value → 内部 state 的同步：

```typescript
useEffect(() => {
  const view = viewRef.current;
  if (view && value !== view.state.doc.toString()) {
    view.dispatch({
      changes: {from: 0, to: view.state.doc.length, insert: value},
    });
  }
}, [value]);
```

判断 `value !== 当前内容` 避免循环：用户输入触发 `onChange` → 父组件 setState → value prop 变 → 同步 effect 跑 → 但内容已一致，跳过。

## updateListener 的用途

`EditorView.updateListener.of(cb)` 在每次 dispatch 后调用，`cb` 收到 `Update` 对象能查 `update.docChanged`、`update.selectionSet` 等。用它做：

- 文档变化时 `onChange` 通知父组件；
- 选区变化时更新光标位置（若需要显示行列号）；
- 焦点变化时通知父组件（用于 Shift-Enter 只在当前 cell 触发 run）。

## 为什么不用 react-codemirror2

社区有 `@uiw/react-codemirror` 等封装库，省去手写 effect。教学版手写是为了让读者看清 CM6 与 React 的边界——封装库藏起同步逻辑，遇到 bug 反而难调。理解了这套手写封装，再用封装库就心里有数。

CM6 集成的核心就三件事：**mount 时建 view、unmount 时销毁、外部 value 变化时 dispatch 同步**。其余扩展（高亮、keymap、listener）都是配置项，加在 `extensions` 数组里即可。
