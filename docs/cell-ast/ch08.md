# AST 遍历实战

上一章我们说明了为什么选 AST，这一章动手遍历。理解后续的 defs/refs 提取，必须先看清 AST 长什么样、`Name` 节点的 `ctx` 又如何区分读写。

## `ast.parse`：源码到树

```python
import ast
code = "y = x + 1"
tree = ast.parse(code)
print(ast.dump(tree, indent=2))
```

输出大致是：

```
Module(body=[
  Assign(
    targets=[Name(id='y', ctx=Store())],
    value=BinOp(
      left=Name(id='x', ctx=Load()),
      op=Add(),
      right=Constant(value=1)
    )
  )
])
```

可以看到，顶层是一个 `Module`，它的 `body` 是语句列表。这里只有一条 `Assign`，其 `targets` 是要赋值的名字（`y`，`ctx=Store`），`value` 是右侧表达式（一个 `BinOp`，左操作数是 `x`，`ctx=Load`）。`Constant(1)` 是字面量，不是 `Name`，所以不会被误当成变量。

## `ast.walk`：遍历所有节点

`ast.walk(tree)` 是一个生成器，按深度优先吐出树里的每一个节点。我们常用它做"地毯式扫描"：

```python
for node in ast.walk(tree):
    print(type(node).__name__)
# Module, Assign, Name, BinOp, Name, Add, Constant
```

对提取 refs 来说，只要在循环里挑出 `isinstance(node, ast.Name) and isinstance(node.ctx, ast.Load)` 的节点，就能拿到所有"被读取"的名字。对提取 defs，则要更精细地看**顶层语句**的类型，这一点下一章详述。

## `Name.ctx` 的三种取值

`Name` 节点代表一个标识符的使用，它的 `ctx` 字段是判断语义的关键：

| ctx      | 含义       | 典型出现位置                |
|----------|------------|-----------------------------|
| `Load`   | 读取变量   | 表达式、函数调用参数        |
| `Store`  | 写入变量   | 赋值左侧、for 循环目标      |
| `Del`    | 删除变量   | `del x` 中的 `x`            |

同一个名字在不同位置会有不同 ctx。例如 `x = x + 1` 里，右侧的 `x` 是 `Load`，左侧的 `x` 是 `Store`。再如 `for i in range(10): ...`，循环变量 `i` 的 `Name` 节点 ctx 是 `Store`，而 `range` 是 `Load`。

## 不同语句的 AST 结构

理解几种常见语句的树形，对后面写提取器很有帮助。

**函数定义** `def f(a): return a`：

```
FunctionDef(name='f', args=arguments(args=[arg(arg='a')]), body=[Return(...)])
```

`FunctionDef.name` 是字符串 `'f'`（不是 `Name` 节点），形参 `a` 在 `args` 里。函数名 `f` 是 cell 的 def，但函数体内的 `a` 是局部变量，不算 cell 的 ref。

**导入** `import numpy as np`：

```
Import(names=[alias(name='numpy', asname='np')])
```

绑定名是 `asname`（若存在）否则是 `name`，即 `np`。

**for 循环** `for i in items: total += i`：

```
For(target=Name(id='i', ctx=Store()), iter=Name(id='items', ctx=Load()), body=[...])
```

`target` 里的 `i` 是 cell 的 def（循环结束后 `i` 仍可见），`iter` 里的 `items` 是 ref。

**增量赋值** `x += 1`：

```
AugAssign(target=Name(id='x', ctx=Store()), op=Add(), value=Constant(1))
```

`AugAssign.target` 的 ctx 是 `Store`，但它同时意味着"先读后写"，所以 `x` 既要进 defs 也要进 refs——这是下一章的重点之一。

掌握了这些结构，我们就能针对每种节点写出准确的提取规则。
