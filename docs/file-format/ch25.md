# parser 实现：从 .py 到依赖图

`backend/storage/parser.py` 里的 `py_to_graph` 负责把一个 `.py` 文件解析回 CellGraph。它纯粹用 Python 标准库的 `ast` 模块，不依赖任何第三方解析器。

## 第一步：ast.parse 找装饰函数

```python
import ast

def py_to_graph(source: str) -> CellGraph:
    tree = ast.parse(source)
    cell_nodes = []
    for node in ast.walk(tree):
        if isinstance(node, ast.FunctionDef):
            for dec in node.decorator_list:
                if (isinstance(dec, ast.Call)
                    and isinstance(dec.func, ast.Attribute)
                    and dec.func.attr == "cell"):
                    cell_nodes.append(node)
    return _build_graph(cell_nodes)
```

`ast.parse` 把源代码解析成 AST，`ast.walk` 遍历找所有 `FunctionDef`。判断它是不是 cell，看装饰器列表里有没有 `@app.cell` 这种形式——即 `ast.Call` 包着 `ast.Attribute`，属性名是 `"cell"`。这样能兼容 `@app.cell`、`@marimo.App.cell` 等写法。

## 第二步：从参数提取 refs

找到 cell 函数后，参数列表就是 refs：

```python
def _extract_refs(func: ast.FunctionDef) -> list[str]:
    refs = []
    for arg in func.args.args:
        refs.append(arg.arg)
    return refs
```

`func.args.args` 是位置参数列表，每个 `arg` 的 `.arg` 属性是参数名。我们只取位置参数，不处理 `*args`、`**kwargs`、默认值——cell 不该有这些复杂签名。参数名就是上游变量名，直接进 refs。

## 第三步：从 return 提取 defs

```python
def _extract_defs(func: ast.FunctionDef) -> list[str]:
    defs = []
    if func.returns is None:
        return defs
    if isinstance(func.returns, ast.Tuple):
        for elt in func.returns.elts:
            if isinstance(elt, ast.Name):
                defs.append(elt.id)
    elif isinstance(func.returns, ast.Name):
        defs.append(func.returns.id)
    return defs
```

注意这里读的是 `func.returns`——AST 里 return 语句的值表达式。如果是元组，逐个取元素名；如果是单个 `Name`，直接取 `.id`。空 return 或没有 return 则 defs 为空。

## 第四步：ast.unparse 提取函数体

cell 的代码是函数体去掉装饰器和签名：

```python
def _extract_code(func: ast.FunctionDef) -> str:
    body = ast.Module(body=func.body, type_ignores=[])
    return ast.unparse(body)
```

把 `func.body`（一个语句列表）包成 `Module` 再 `ast.unparse`，就得到干净的代码文本。`ast.unparse` 是 Python 3.9+ 的功能，能把 AST 反向生成代码字符串。代价是它会丢失原始格式（空行、注释、特定缩进风格），所以 marimo 在保存时会尽量保留原始源码片段而非 reparse 后的版本——但教学版用 unparse 足过这个优化。

## 第五步：构建图

```python
graph = CellGraph()
for func in cell_nodes:
    cid = _gen_id(func)
    refs = _extract_refs(func)
    defs = _extract_defs(func)
    code = _extract_code(func)
    graph.add_cell(Cell(id=cid, code=code, refs=refs, defs=defs))
return graph
```

每个 cell 分配一个 ID（可用函数名或位置序号），连同 refs、defs、code 一起塞进 CellGraph。graph 内部会根据 refs/defs 自动连边。

整个 parser 不执行任何用户代码，纯静态分析——这是 marimo 能在不运行 notebook 的情况下构建依赖图、检测循环、做拓扑排序的根本原因。
